FAQ

Frequently asked questions

Does Assisty replace my judgment as an examiner?
No. Assisty is an assistant, not an autopilot. You retain 100% authority to review low-confidence cases, edit feedback, override points, and sign off before grades are released.
How does it grade subjective answers with no single right answer?
It evaluates against 5-level behavioural rubrics calibrated on actual student response variations, assessing open-ended reasoning rather than exact string-matching.
How do I know the system isn’t miscalculating or hallucinating marks?
Assisty mandates exact text citations for every point awarded (no evidence = zero score) and runs 3-pass consensus verification on every script.
Is student data secure?
Yes. Data is encrypted in transit and at rest within institutional infrastructure and is never used to train public algorithms or shared externally.
Can I control how strictly work is marked?
Yes. Every batch can be run at lenient, moderate or strict calibration, and re-run to compare grade curves before you release marks.
